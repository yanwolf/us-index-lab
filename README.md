# us-index-lab — 指數回測室

把 txf-sim 的台指策略移植到指數 CFD：標普 500（US500）、那斯達克 100（NAS100）、日經 225（JP225）、恆生指數（HK50），2026-11-26 加黃金（XAUUSD），
用多年 1 分 K 回測、調參數，判斷值不值得之後在 MT5 上程式交易。

## 部署（Coolify）
1. 建 GitHub repo，整包推上去，Coolify 新增服務選 Dockerfile
2. **Persistent Storage：掛一個 volume 到 `/data`**（下載的資料、參數存檔都在這，不掛的話重新部署就沒了）
3. 環境變數照 `.env.example`，至少設 `LAB_PASSWORD`
4. 埠號 8080，健康檢查 `/healthz`
資源：3 年兩個商品約 200MB 磁碟；記憶體 1GB 夠用。最佳化會用滿所有 CPU 核心。

## 使用流程
1. **資料 → 從 Dukascopy 下載**：US500、NAS100 各抓一次（預設 3 年）。可以重複按，只會補缺的日子
2. **回測**：選策略、K 棒週期、期間，先用預設參數跑一次看基準
3. **最佳化**：勾 2–3 個參數掃描。優先看三件事：
   - **滾動驗證**：定期重新調參數、接起來的測試段績效，跟同期買進持有比
   - **排名一致性／優於中位數**：樣本內挑得準不準（扣掉行情的共同影響）
   - **行情偏多警示**：連最差參數在樣本外都賺錢時，樣本外的數字不能當證據
4. 點最佳化結果的一列 → 自動帶回回測頁看完整報告 → 喜歡就「存目前參數」
5. **MT5 校準**（見下）：用要下單那家券商的實際點差，回填成本後重跑

## GuYuan_2024 多空（2026-11 交接版）
- `GuYuan_2024`（只做多）、`GuYuan_2024_S`（只做空，鏡像）。交接文件：txf-sim 的 GUYUAN_HANDOFF.md
- 新參數：`SES`（CloseS 時段定義）、`MA1/MA2`（均線濾網，只管進場）、`EBX`（進場 K 災難停損 = AvgRange(200)×EBX，只在進場那根 K 有效）
- `SES`：0 主時段／延長時段（現貨開收盤切兩段，預設，類比台指日夜盤）、1 交易日（= CloseD）、
  2 等長兩段（交易日切換點起每 12 小時）、3 東京 09:00／倫敦 08:00／紐約 09:30 開盤切三段
- 結算日出場已拿掉；週末用 `WKX`：每週最後一筆報價前幾分鐘出場（各指數自己的週五收盤）
- 「多空批次」頁：一次在多個指數跑多方、空方、多空合跑，預設用台指最終版參數（點數換成單位：1 單位 ≈ 台指 90 點，**此換算已過時**，見下方「和台指版的差異」）
- 驗證：`tests/test_guyuan.py`（預設參數跟舊版逐筆相同、空方在翻轉行情上跟多方逐筆相同、EBX、SES）

## 黃金 XAUUSD（2026-11-26）
台指策略原封不動放到黃金上試。黃金在 gold-scalper 試過的短線技術策略（纏論、布林、斐波那契…）都撐不過成本或不穩定，
這裡是另一類邏輯（以時段為基礎的趨勢跟隨），而且 MT5 成本每筆約 0.45 點、只有日波幅的 1% 左右，跟那指差不多。
- 商品設定（`app/instruments.py`）：Dukascopy 代碼 `XAUUSD`；**交易日紐約 17:00 換日**；**主時段紐約 08:20–13:30**（COMEX 正規時段），
  其餘算「其他時段」，CloseS 在這兩段之間切。黃金沒有天然的日夜盤，這是自己定的。
- 成本：點差 0.25、滑價每邊 0.1（Pepperstone；之後用 cfd-live 的 `gold_chan15` 實際成交校準）。
  庫存費用 Pepperstone 點模式換算：做多每晚約 −0.81 點、做空約 +0.28 點，換成這裡「每交易日、年化 % ÷ 360」＝ 多 9.9%、空 −3.5%。
- 1 單位＝1 盎司（MT5 0.01 手），1 點＝1 美元。
- 用法：「資料」頁選黃金、開始日填 2021-01-01 下載（含 2022 年 3–11 月的下跌）→ 範本「⑩ 黃金」九組：多方 GuYuan_2025（20、60 分 K）、
  GuYuan_2024、AR_crossover、TMFF（多空），空方 GuYuan_2024_S、AR_crossunder、TMFF_S，加一組滑價加倍。
  有苗頭的再掃描（平台分數、滾動驗證），跑出來的參數可以直接在 cfd-live 加一支 XAUUSD 實例前瞻測試。
- 測試：`tests/test_gold.py`（商品設定與庫存費換算、08:20／13:30 切 K、17:00 換交易日、所有策略在合成黃金資料上跑得動且庫存費方向正確、
  範本參數合法、Dukascopy 價格倍率三位或兩位小數都判斷得出來）。

## TurtleMA：刀神海龜突破＋均線三刀流（2026-11-26）
不是台指移植，是新寫的波段策略，目的是找一支跟 GuYuan_2025 低相關、可以做空的策略。
- 方向（海龜）：收盤突破前 `DC` 根最高 → 偏多、跌破前 `DC` 根最低 → 偏空，狀態延續。60 分 K 的 DC=80 ≈ 4 小時 K 的 20 根
- 進場（三刀流）：偏多且 MA1>MA2>MA3（20>60>240）、MA1 斜率向上 → 下一根開盤市價多；空方鏡像。`SIDE` 0 多空／1 只多／-1 只空
- 出場：硬停損 `LOSS` 單位、MA1 斜率反轉（`XS`，張飛）、方向翻轉；`X60=1` 加上跌破／站上 MA2（關羽）。**沒有固定停利**
- 跟 GuYuan_2025 的差別：突破週期約長 10 倍、突破只當方向濾網、讓獲利跑、可做空
- 注意：60 分 K 的 240MA 約 10 個交易日，不是年線；預設週五 WKX 會出場，波段策略另外測 WKX=0
- 範本 ⑪：五個商品 × 多空／只多／只空；⑪b：DC × LOSS × SLP 掃描、X60、WKX=0
- **相關性**：到「組合」頁放 TurtleMA 和 GuYuan_2025 同一商品兩腳，看相關係數表（< 0.3 才算真的互補）
- 測試：`tests/test_turtle_ma.py`（多空鏡像逐筆相同、每筆進場重算規則核對且以下一根開盤成交、無固定停利、範本合法）

## 抄底訊號（2026-11）
「抄底訊號」分頁：收集日線資料，比較「訊號出現後買進」和「任意一天買進」的報酬。程式在 `app/bottom.py`，測試 `python tests/test_bottom.py`（假網路回應，手算對照）。
- 資料來源：Yahoo（S&P 500、那斯達克 100、黃金／白銀期貨、成分股）、Cboe（VIX、P/C）、GitHub whit3rabbit/fear-greed-data＋CNN（恐懼貪婪）、
  GitHub fja05680/sp500（S&P 歷史成分股起訖日）、維基百科（那斯達克 100 現在的成分股）。存在 `/data/bottom/`
- S5FI／NDFI 自己算（站上 50 日均線的成分股比例）。S5FI 用當時的成分股；NDFI 只有現在的成分股，早期偏樂觀
- 進場：訊號日隔天收盤。同一波：前 N 天（預設 20）沒訊號才算新的一波。「勝過隨機」95% 以上才算顯著
- 第一次含成分股收集約 15–30 分鐘；Yahoo 限流時調大 `BOTTOM_YAHOO_DELAY`（預設 0.35 秒）或把 `BOTTOM_YAHOO_WORKERS` 改 1

## 最佳化：平台分數（不選孤峰）
「挑選方式」預設用平台分數：每組參數跟「任一參數往上或往下一格」的鄰居一起取中位數再排序，
孤峰會被拉低。表格多了「平台分數」「鄰近最差」兩欄，鄰近最差為負代表旁邊一格就虧。滾動驗證每段也用平台分數挑。

## 判斷值不值得的標準（建議）
- 參數不重新優化或只微調，樣本外仍賺錢
- 交易數 > 100、獲利因子 > 1.3（扣成本後）
- **報酬／回撤要優於買進持有**：只做多的策略在美股長期多頭下，這一關最容易輸
- 參數附近一片都不錯（不是孤立的一個尖峰）

## 和台指版的差異
| 項目 | txf-sim（台指） | us-index-lab |
|---|---|---|
| 停損停利 | 固定點數 | 單位 × 倍數。單位 = 進場前 AvgRange(UNIT_N)，或 0.1% 價格（UNIT_MODE=1） |
| 交易日 | 期交所交易日 | 依商品切換：美股美東 18:00、日經東京 16:00、恆指香港 17:00；週五夜盤歸下週一 |
| 時段 CloseS | 日盤／夜盤 | 主時段／延長時段：美股 09:30–16:00、日經 08:45–15:45、恆指 09:15–16:30 |
| 結算日出場 | 有 | 無（CFD 沒有結算） |
| 週末 | 週六 TNw 後出場 | 每週最後一筆報價前 WKX 分鐘出場（預設 15），直接看資料的休市缺口 |
| 成本 | 手續費＋滑價 | 點差＋滑價＋隔夜利息（年化 %） |

撮合規則與 MC 一致：收盤後掛下一根的單、1 分 K 內觸價、一根 K 最多成交一次、
跳空以開盤價成交、同一分鐘停損停利都碰到以停損先算（保守）。
策略預設參數是台指原參數的粗略換算，只是起點。

**「1 單位 ≈ 台指 90 點」已過時（2026-11）**：當初假設台指 60 分 K 的 AvgRange(100) 約 90 點，
但台指從 1.2 萬漲到 3～4 萬，現在 AvgRange(200) 約 530 點。台指那邊固定點數的停損停利早就變得相對很緊，
所以策略預設值、`TXF_PRESET` 和「多空批次」的「台指參數」都只是換算起點，不代表台指那組參數今天的實際行為。
參數本身沒有改。txf-sim 已陸續改成 AvgRange(200) 倍數（例如 AR_crossover：停損 4、停利 8、移動停利 0.8／回吐 1.6），
這邊對應的寫法是 `UNIT_N=200` 加上同樣的倍數。

- **AR_crossunder（空）降低優先順序**：台指上掃 60 組全部虧（PF ≤ 0.84、2022 空頭也只打平）；
  這邊 ② 三個指數掃描與 ⑫ 那指新出場也都失敗（PF 0.84～0.97、0.88），不再花時間。

## MT5 券商探測（Windows）
```
pip install MetaTrader5 pandas
python tools/mt5_probe.py --broker pepperstone --terminal "C:\...\terminal64.exe"
```
先在 MT5「工具 → 選項 → 圖表 → 圖表中最大K線數」設成最大並重開。
每家跑一次，產出：
- `mt5_<券商>_report.json`：合約規格、點差、隔夜利息、1 分 K 能回溯多遠
- `mt5_<券商>_US500_M1.csv` 等：到「資料」頁匯入，再到「資料比對」和 Dukascopy 對照，取得實際點差
